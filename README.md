# # GerBar Load Planner

GerBar Load Planner es una plataforma profesional para la planificación, optimización y simulación de carga de contenedores, camiones y semirremolques.

## Objetivos

- Optimizar el uso del espacio.
- Balancear el peso de la carga.
- Reducir costos logísticos.
- Generar planos de carga en 2D y 3D.
- Simular operaciones de carga y descarga.
- Integrar inteligencia artificial para optimización avanzada.

## Tecnologías

- Frontend: React + TypeScript
- Backend: FastAPI
- Base de datos: PostgreSQL
- Optimización: Google OR-Tools
- Visualización 3D: Three.js
- Contenedores: Docker

Versión inicial: 0.1.0
